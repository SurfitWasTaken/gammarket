# research/ — publishable material

Everything in this folder is generated by the simulator and fully
reproducible. The paper is `paper.md`; every number in it traces to a
`metrics.json` under `experiments/` or to `figures/mechanism_stats.json`,
and every experiment's `manifest.json` records the resolved config, seeds,
measurement spec, and git commit that produced it.

## Layout

```
paper.md                    the working paper (figures referenced by relative path)
configs/phase6_regime.yaml  paper-only config: phase6.yaml + sentiment regime (§6.2)
experiments/
  baseline_flat/            validated static-surface config, seeds 42/7/123 (§5)
  ewma_surface/             calibrated EWMA config (lambda 0.99), seeds 42/7/123 (§5, §6.3)
  ablation_no_feedback/     vol_feedback off — zero-intelligence flow (§6.1)
  regime/                   feedback + sentiment regime (§6.1–6.2)
figures/                    cross-experiment comparison figures + their stats JSON
make_figures.py             regenerates figures/ (~1 min)
```

Each experiment directory contains `experiment.md` (human-readable
summary), `metrics.json` (fact verdicts + microstructure metrics per
seed), `manifest.json` (provenance), and the standard five-figure set for
its headline seed. Per-step/fill/bar CSVs are omitted from the repo for
size; regenerate them by re-running the experiment without `--no-csv`.

## Reproduce

From the repository root:

```bash
.venv/bin/python run_experiment.py --out research/experiments/baseline_flat --no-csv \
    --label "Validated flat-surface configuration (phase6.yaml), pre-registered seeds"

.venv/bin/python run_experiment.py --config sim/config/phase6_ewma.yaml \
    --out research/experiments/ewma_surface --no-csv \
    --label "Calibrated EWMA dynamic-surface configuration (ewma_lambda 0.99)"

.venv/bin/python run_experiment.py --out research/experiments/ablation_no_feedback --no-csv \
    --set agents.retail.vol_feedback=0.0 \
    --label "Ablation: vol_feedback off (baseline noise flow only)"

.venv/bin/python run_experiment.py --config research/configs/phase6_regime.yaml \
    --out research/experiments/regime --no-csv \
    --label "Mechanism study: calm/excited sentiment regime on top of vol_feedback"

.venv/bin/python research/make_figures.py
```

Each command takes ~1 minute (3 seeds × 60,000 events). Runs are
deterministic given (config, seed); regenerated outputs differ only in
timestamps and wall-time fields.

See `docs/RESEARCH.md` for the general experiment workflow and
`CLAUDE.md` (F1–F9) for the frozen measurement contracts the paper's
tests rely on.
